## 目录

- [设备硬件](/device-hardware/) — GPU 的物理组成：SM、Tensor Core、显存等
- [设备软件](/device-software/) — 运行在 GPU 上的软件抽象：线程、warp、核函数、内存层次等
- [主机软件](/host-software/) — CPU 侧的软件栈：驱动、CUDA API、nvcc、cuBLAS 等
- [性能](/perf/) — 优化 GPU 程序性能所需的关键概念：占用率、访存合并、roofline 模型等
